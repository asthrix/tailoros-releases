# TailorOS native releases

This public repository contains approved TailorOS desktop installers and update metadata. Application source remains private.

Windows previews use architecture-specific NSIS installers. Mac previews use separate Apple Silicon and Intel DMGs and install manually. Preview activation packages and private signing keys are never public release assets.

No qualified preview is currently published. Download only an approved version from this repository's Releases page, follow its release notes, and verify its checksums.

The protected `preview` branch will contain `latest.json` only after an approved preview candidate has been published and verified anonymously. Do not use GitHub's latest stable release route for preview updates.
